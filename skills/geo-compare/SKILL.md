# GEO 月度增量报告生成器

## 用途

GEO 服务商最有力的续费工具：向客户**精确**展示与你合作以来哪里变好了。
GEO 评分每涨一分，都是服务价值的证据。这个 skill 生成那份"这是你的进展"报告。

---

## 命令

```
/geo-cn compare <域名>
/geo-cn compare <基线文件> <当前文件>
/geo-cn compare mingchuan-edu.cn --month 2026-08
```

**示例：**
```
/geo-cn compare mingchuan-edu.cn
/geo-cn compare ~/.geo-prospects/audits/mingchuan-edu.cn-2026-07-15.md ~/.geo-prospects/audits/mingchuan-edu.cn-2026-08-20.md
```

---

## 工作流程

### 第 1 步：找到审计文件

只提供域名时：
1. 在 `~/.geo-prospects/audits/` 中查找匹配 `<域名>-*.md` 的文件
2. 按日期排序
3. 最早的作基线，最新的作当前
4. 只有一份文件时：以它为基线，跑一次新的快速审计作当前
5. 一份都没有时：建议先跑 `/geo-cn prospect audit <域名>`

### 第 2 步：解析两份审计

从每份审计文件中提取：
- GEO 综合评分
- 分类评分（6 个类目）
- 分平台评分（6 个国内平台）
- AI 爬虫状态
- 严重问题清单
- 整改项清单及状态

### 第 3 步：计算增量

对每个指标：
- 增量 = 当前 - 基线
- 趋势 = ▲（提升）、▼（下降）、──（持平）
- 报告中用颜色编码：绿（+）、红（-）、灰（=）

### 第 4 步：生成月度报告

输出到 `~/.geo-prospects/reports/<域名>-monthly-<日期>.md`

## 增量计算逻辑

解析两份审计文件时，查找这些模式：

```
需要提取的评分标记：
- "GEO 评分: XX/100"
- "综合评分: XX"
- "AI 可引用性: XX/100"
- "品牌权威: XX/100"
- "技术: XX/100"
- "Schema: XX/100"
- "平台: XX/100"
- "内容: XX/100"
- "Bytespider: 已放行/已屏蔽"
- "Baiduspider: 已放行/已屏蔽"
```

如果审计文件里找不到精确评分，根据文中描述的问题做上下文分析，
估算近似评分。

---

## 趋势解读

| 增量 | 趋势符号 | 含义 |
|-------|-------------|---------|
| +5 及以上 | ▲▲ | 显著提升 |
| +1 到 +4 | ▲ | 提升 |
| 0 | ── | 持平 |
| -1 到 -4 | ▼ | 小幅下降 |
| -5 及以上 | ▼▼ | 明显下降 —— 需要沟通 |

下降不一定是坏事 —— 可能只是新审计发现了之前看不到的问题。
把下降表述为"新发现的机会点"。
