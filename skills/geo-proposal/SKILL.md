# GEO 提案生成器

## 用途

生成一份完全定制、可直接发送客户的中文 GEO 服务提案，做到：

1. 直接引用该客户的 GEO 审计发现
2. 把技术短板翻译成客户听得懂的商业痛点
3. 给出三档服务包和清晰的人民币报价
4. 包含务实的 ROI 测算
5. 输出专业 markdown 文档，无需再编辑即可发送

---

## 命令

```
/geo-cn proposal <域名或审计文件> [--tier basic|standard|premium] [--client-name "客户名"] [--monthly 金额]
```

**示例：**
```
/geo-cn proposal mingchuan-edu.cn
/geo-cn proposal mingchuan-edu.cn --tier standard --client-name "杭州明川教育科技有限公司"
/geo-cn proposal ~/.geo-prospects/audits/mingchuan-edu.cn-2026-08-20.md
```

## 工作流程

### 第 1 步：加载审计数据

1. 检查 `~/.geo-prospects/audits/<域名>*.md` 是否存在
2. 不存在则建议先跑 `/geo-cn quick <域名>`
3. 从审计中提取：
   - GEO 综合评分及分类评分
   - 最严重的 3 个发现
   - 速赢项清单
   - 业务类型
   - 预估自然流量影响

### 第 2 步：定制提案

自动填充提案模板：

- 公司名（从域名或客户记录获取）
- GEO 评分与档位标签
- 最严重的 3 个痛点（翻译成商业语言）
- AI 搜索转移带来的营收风险估算
- 按评分推荐服务档位：
  - 评分 0-40 → 推荐旗舰版（问题严重，需要全面投入）
  - 评分 41-60 → 推荐标准版（差距明显，需要按月持续优化）
  - 评分 61-75 → 推荐基础版（基础不错，需要监测维护）

### 第 3 步：生成提案文件

输出到 `~/.geo-prospects/proposals/<域名>-proposal-<日期>.md`
如 `~/.geo-prospects/prospects.json` 中已有该客户记录，同步更新。
